           Tree-based Chained Hash Integrity Coding for HTTP
                 draft-meunier-httpbis-tree-chic-latest

Abstract

   This describes a content-coding for HTTP that enables progressive
   processing of content, with ranges, without sacrificing integrity.

1.  Introduction

   [CHIC] describe a chained hash integrity coding for HTTP.  To allow
   for partial validation of an HTTP resource, using a merkle tree based
   construction seems more appropriate.  It would allow for ranges,
   sending content out-of-order, while maintaining integrity and minimal
   overhead.
